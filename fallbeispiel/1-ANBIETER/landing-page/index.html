Konkrete Fähigkeiten, keine Theorie

Nach diesem Kurs sind das normale Handgriffe für dich — keine Suche bei Google mehr nötig.

cd ~/projekte && ls -la

Dich durch das Dateisystem bewegen, ohne nachzudenken.

chmod +x deploy.sh

Rechte verstehen und setzen — und wissen, warum sudo gefährlich sein kann.

ps aux | grep node

Prozesse finden, beobachten und beenden, wenn etwas hängt.

sudo apt update && apt upgrade

Software installieren und das System aktuell halten.

ssh user@server -p 22

Dich auf entfernte Rechner verbinden und Dateien übertragen.

for f in *.log; do ...; done

Kleine Shell-Skripte schreiben, die dir Arbeit abnehmen.
